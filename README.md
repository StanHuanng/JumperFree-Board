# JumperFree-Board

> 团队项目 | 高电位队

本项目是由高电位队发起和开发，致力于对 [Architeuthis-Flux/JumperlessV5](https://github.com/Architeuthis-Flux/JumperlessV5) 的复刻与改进，打造下一代无跳线面包板。

## 项目简介

JumperFree-Board 继承了 JumperlessV5 的核心设计思想，并结合自身开发需求做了适配。本项目专注于逐步实现矩阵式开关芯片和灯组的驱动，并最终完成高性能、可扩展的无跳线实验板 PCB。

## 团队介绍

**高电位队** —— 专注于单片机与FPGA电子开发与原型设计。团队成员涵盖硬件、嵌入式软件、PCB 设计等领域，力求推动实验平台的发展与普及。

## 开发计划

项目开发流程分为以下几个主要阶段：

1. **F103平台初步测试**
   - 使用 STM32F103 微控制器，搭建基本原型
   - 测试开关芯片的可靠性与矩阵灯组驱动（如 I/O 扩展，电流稳定性）
   - 记录测试过程与遇到的问题，调整原理设计

2. **H743平台功能拓展**
   - 用 STM32H743/H753 高性能主控平台进行进一步测试
   - 验证高速通信与更多 GPIO 资源下的驱动效果，优化软件架构
   - 搭建功能完整的 demo 板，实现核心功能

3. **PCB 设计与完善**
   - 基于前两阶段测试，设计完整的 JumperFree-Board PCB
   - 考虑工艺可行性、电源布局、信号完整性等关键参数
   - 设计多层板，集成所有关键模块

4. **中间必要步骤与说明**
   - 硬件选型：包括开关芯片、灯珠、供电芯片等器件
   - 关键电路设计：矩阵驱动及防漏电、防干扰设计说明
   - 软件调试手册：从点亮单颗 LED 到批量驱动的流程
   - 原型验证记录：每一步硬件和软件测试过程记录
   - PCB 制板建议与常见问题处理
