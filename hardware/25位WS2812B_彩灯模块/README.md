# 25位 WS2812B 彩灯模块

这是一个基于 WS2812B 全彩 LED 灯珠设计的 25 位点阵模块，适用于各种创意显示和灯光装饰项目。

## 1、项目简介

本项目设计了一款 5x5 排列的 LED 矩阵板，板载 25 颗 WS2812B 灯珠。WS2812B 是集控制电路与发光电路于一体的智能外控 LED 光源。其外型与 5050LED 灯珠相同，每个元件即为一个像素点。

*   **文件说明**：
    *   `ProPrj_25位WS2812B_彩灯模块.epro2`: 嘉立创 EDA 专业版工程文件。
    *   `SCH_25位WS2812B_彩灯模块.png`: 原理图预览。
    *   `3D渲染图_25位WS2812B_彩灯模块.png`: PCB 3D 效果预览。

## 2、原理解析

*   **控制原理**：采用单总线归零码通讯方式。像素点上电复位后，DIN 端接收控制器传输的数据。前 24bit 数据被第一个像素点提取后，送入内部数据锁存器，剩余数据通过内部整形处理电路整形放大后通过 DOUT 端口开始转发输出给下一个级联的像素点。
*   **电源设计**：模块使用 5V 供电。在电源输入端并联电容（如 100nF 或更大）以滤除电源噪声，保证灯珠工作稳定。

## 3、使用说明

### 硬件连接
通常模块引出以下接口（具体请参考原理图）：
*   **VCC**：接 +5V 电源
*   **GND**：接电源地
*   **DIN**：信号输入，接单片机 GPIO
*   **DOUT**：信号输出（可选），用于级联下一个 WS2812B 模块

### 软件驱动
支持多种主流控制器和库：
*   **Arduino/ESP32**: 推荐使用 `Adafruit NeoPixel` 或 `FastLED` 库。
*   **STM32**: 可使用 PWM + DMA 方式驱动。
*   **MicroPython**: 使用内置的 `neopixel` 模块。
